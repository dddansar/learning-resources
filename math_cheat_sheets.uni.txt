Completing the square:
x²+b*x+c = (x+(b/2))² - b²/4 + c

Quadratic formula: the roots of ax²+bx+c: (-b±√(b²-4ac))/(2a)
If two quadratic equations have both roots common, then
   a₁/a₂ = b₁/b₂ = c₁/c₂
If only one common room then
   α=(c₁a₂-c₂a₁)/(a₁b₂-a₂b₁)=(b₁c₂-b₂c₁)/(c₁a₂-c₂a₁)

Location of Roots:
Let f (x) = ax² + bx + c, where a > 0 & a,b,c ∈ R.
(i)Conditions for both the roots of f(x) = 0 to be greater than a specified number x₀ are:
   b² - 4ac ≥ 0; f(x₀) > 0 & (-b/2a) > x₀.
(Ii)Conditions for both the roots of f(x) = 0 to be smaller than a specified number x₀ are:
   b² - 4ac ≥ 0; f(x₀) > 0 & (-b/2a) < x₀.
(Iii)Conditions for both roots of f(x) = 0 to lie on either side of the number x₀ (in other words the number x₀ lies between the roots of f (x) = 0), is:
   f(x₀) < 0.
(Iv)Conditions that both roots of f (x) = 0 to be confined between the numbers x₁ and x₂, (x₁ < x₂) are:
   b² - 4ac ≥ 0; f(x₁) > 0 ; f(x₂) > 0 & x₁ < (-b/2a) < x₂.
(v)Conditions for exactly one root of f(x) = 0 to lie in the interval (x₁, x₂) i.e. x₁ < x < x₂ is:
   f(x₁)f(x₂) < 0

Cubic & higher degree equations
-------------------------------
Consider the cubic equation ax³ + bx² + cx + d = 0.
The equation would have 3 roots (equal to the degree of the equation). Some of them can be imaginary. If the roots are denoted as α, β and γ, we have
α+β+γ=-b/a
αβ+αγ+βγ=c/a
αβγ=-d/a

The above can be extended for higher degree equations as well. For an 'n' degree equation,
Sum of roots = - coefficient of xⁿ⁻¹/coefficient of xⁿ
Sum of roots taken two at a time = coefficient of xⁿ⁻²/coefficient of xⁿ
Sum of roots taken 'r' at a time =(-1)ʳ coefficient of xⁿ⁻ʳ/coefficient of xⁿ

Product of roots = (-1)ⁿ constant term/coefficient of xⁿ

Remainder Theorem:
To identify whether a given expression is a factor of another expression, we can take help of Remainder Theorem.
According to the remainder theorem, when any expression f(x) is divided by (x - a), the remainder is f(a). (a is any constant in this example).

Factor Theorem:
An expression is said to be a factor of another expression only when the remainder is 0 when the latter is divided by the former. (x - a) is a factor of f(x) if and only if f(a) = 0.

Some Partial differential Equations
-----------------------------------
The Laplace Equation
∂²u/∂x² + ∂²u/∂y² = 0
Applies to potential energy function u(x,y) for a conservative force field in the xy-plane. Partial differential equations of this type are called elliptic.

The Heat Equation
∂²u/∂x² + ∂²u/∂y² = ∂u/∂t
Applies to the temperature distribution u(x,y) in the xy-plane when heat is allowed to flow from was areas to cool ones. The equations of this type are called parabolic

The Wave equation
∂²u/∂x² + ∂²u/∂y² = ∂²u/∂²t
Applies to the displacement of vibrating membranes and other wave functions. The equations of this type are called hyperbolic.

Laws of Algebra of sets (Properties of sets):
(1) Commutative law : (A∪B) = B∪A ; A∩B = B∩A

If A, B, C are finite sets and U be the finite universal set then
(1) n(A∪B) = n(A) + n(B) - n(A∩B)
(2) n(A - B) = n(A) - n(A∩B)
(3) n(A∪B∪C) = n(A) + n(B) + n(C) - n(A∩B) - n(B∩C) - n (A∩C) + n(A∩B∩C)
(4) Number of elements in exactly two of the sets A, B, C = n(A∩B) + n(B∩C) + n(C∩A) - 3n(A∩B∩C)
(5) Number of elements in exactly one of the sets A, B, C = n(A) + n(B) + n(C) - 2n(A∩B) - 2n(B∩C) - 2n(A∩C) + 3n(A∩B∩C)

(1) Void relation : Let A be a set. Then ф ⊆ A × A and so it is a relation on A. This relation is called the void or empty relation on A.
(2) Universal relation : Let A be a set. Then A × A ⊆ A × A and so it is a relation on A. This relation is called the universal relation on A.
(3) Identity relation : Let A be a set. Then the relation IA = {(a, a) : a ∈ A} on A is called the identity relation on A. In other words, a relation IA on A is called the identity relation if every element of A is related to itself only.
(4) Reflexive relation : A relation R on a set A is said to be reflexive if every element of A is related to itself. Thus, R on a set A is not reflexive if there exists an element a ∈ A such that (a, a) ∉ R. Note : Every identity relation is reflexive but every reflexive relation in not identity.
(5) Symmetric relation : A relation R on a set A is said to be a symmetric relation
Iff (a, b) ∈ R ⇒ (b ,a) ∈ R for all a, b ∈ A.
i.e. a R b ⇒ b R a          for all a, b ∈ A.
(6) Transitive relation : Let A be any set. A relation R on A is said to
Be a transitive relation
Iff (a, b) ∈ R and (b, c) ∈ R ⇒ (a, c) ∈ R for all a, b, c ∈ A
i.e. a R b and b R c ⇒ a R c
For all a, b, c ∈ A
(7) Equivalence relation : A relation R on a set A is said to be an equivalence relation on A iff
   (A) it is reflexive  i.e. (a, a) ∈ R for all a ∈ A
   (B) it is symmetric  i.e. (a, b) ∈ R ⇒ (b, a) ∈ R for all a, b ∈ A
   (C) it is transitive i.e. (a, b) ∈ R and (b, c) ∈ R ⇒ (a, c) ∈ R for all a,b∈A

CI: Confidence Interval. This is the range of values, calculated from the sample data, that is likely to contain the true population parameter.
b: Point Estimate (e.g., the sample slope in regression, or the sample mean x̅). It is the central value of the interval.
t*: Critical Value (t-score or t-multiplier). This value comes from the t-distribution based on the desired confidence level (e.g., 95%) and the degrees of freedom.

represents the one-sample z-test for a population mean, used when the population standard deviation (σ) is known. It is used to determine if the difference between a sample mean (x̅) and a hypothesized population mean (μ₀) is statistically significant.

x̅: The sample mean.
μ₀: The hypothesized population mean.
σ: The population standard deviation.
n: The sample size.

Minimum sample size n ≥ (z* σ/ME)²

Hypothesis testing is a statistical method used to determine if there is enough evidence in a sample data to draw conclusions that a certain parameter/condition is true for the entire population.
step 1: formulate 2 competing hypothesis, the null hypothesis H₀ and the alternative Hₐ. Ex: Claims that product kills 95% of germs. H₀:μ ≥95% Hₐ:μ<95%, hypothesis testing can use z-test, t-test, chi-square test.
step 2: significance level: the probability of rejecting H₀ when it is true
α ; ex α=0.05
step 3: take a sample: ex n=100; x̅ =94% ; S sample standard deviation
step 4: Calculate p-value=P(x̅≥94 | H₀ is true)
step 5: p-value ≤ α -> Reject Hypothesis H₀
                > α -> Do no reject H₀
Type 1 error: H₀ true, reject H₀
Type 2 error: H₀ false, fail to reject H₀
Power = P(rejecting H₀ | H₀ false) = 1 -P(not rejecting H₀ | H₀ false) = P(not making type 2 error)
Can be increased by increasing α but this also increases P(type 1 error)
Can be increased by increasing n, by decreasing variability, by increasing H₀ distance from parameter (last 2 are usually not controllable)

when to use:
   z-test: population variance is known, otherwise sample size is large n ≥ 30. It is assumed z-statistics follows a standard normal distribution.
   t-test: population variance unknown, sample size small n < 30. It is assumed z-statistics follows a t-distribution with a degree of freedom=n-1.
z-score = (x̅-μ)/(σ/√n)
t-score = (x̅-μ)/(s/√n)
for both z and t:
   independence condition: samples must be independent and must have a distribution identical to the population's (normal), sample must be random. sampling with replacement, sample size ≤ 10% of pop.
   Normal condition: parent population normal, n ≥ 30, sample is symmetric and there are no significant outliers.

z-stats proportions: H₀:P=P₁ ; Hₐ:P≠P₁ ; z = (p̂-P₀)/σₚ̂ ; σₚ̂ =√(P₀(1-P₀)/n); p̂ sample proportion
   -> use z to figure out p-value
t-stats: means: H₀:μ=μ₁ ; Hₐ:μ≠μ₁ ; x̅ sample mean ; sₓ ; z = (x̅-μ₀)/σₓ ; μ₀ assumed mean from the null hypothesis; σₓ standard error of the mean/SD of the sampling distribution of the sample mean ; z ideally use a z-statistic
σ may be unknown, so instead we estimate σₓ̅ ; σₓ̅ = σ/√n
t = (x̅-μ₀)/(sₓ/√n) ; sₓ sample standard deviation

The Quine-McCluskey algorithm (QMC), also known as the method of prime implicants or the tabulation method, is a method used for minimization of Boolean functions

The Petrick method is used to determine all minimum-cost Sum-of-Products (SOP) solutions for a Boolean function after finding the prime implicants. It is specifically used to resolve cases where the Quine-McCluskey method leaves non-essential prime implicants that do not uniquely cover all minterms.

Covering table logic refers to the systematic process of constructing truth tables to evaluate the truth values of complex logical statements, arguments, or to verify logical equivalences.

Shannon expansion (or decomposition) is a fundamental Boolean algebra theorem used to simplify complex logic functions by breaking them into smaller, manageable sub-functions based on a selected variable. It is expressed as F(a,b,...,z)=aF(1,b,..,z)+a̅F(1,b,..,z)=aF(a=1)+a̅F(a=0), allowing for efficient digital circuit design, particularly with multiplexers, transmission gates and CMOS logic, to reduce gate count and power.

Two-level optimization logic minimizes Boolean functions into a Sum-of-Products (SOP) or Product-of-Sums (POS) form, featuring maximum two gate levels between inputs and outputs.

Branch and Bound (B&B) is a powerful algorithm design paradigm for solving complex optimization problems, especially combinatorial problems, by systematically exploring solutions, breaking the problem into smaller parts (branching), and using calculated limits (bounds) to discard unpromising paths, thereby pruning the search space and finding optimal solutions efficiently.

ESPRESSO-EXACT is an exact two-level Boolean logic minimization algorithm that computes a globally minimal representation of a logic function, unlike the faster, heuristic-based Espresso-II. It guarantees the fewest possible cubes in a PLA, often used for smaller, critical circuits.

Positional Cube Notation (PCN) is a method used in digital logic design—specifically in logic minimization and CAD tools—to represent Boolean functions as a set of product terms (cubes). It acts as a compact, machine-readable format for identifying prime implicants in multi-variable Boolean spaces.

The Unate Recursive Paradigm (URP) is a divide-and-conquer strategy in logic synthesis that uses Shannon expansion to recursively break down complex Boolean functions into smaller, "unate" (monotonic) cofactors. By selecting a binate variable for splitting, URP efficiently solves problems like tautology checking, complementation, and prime generation, as unate functions are much easier to manipulate.
